# 邮生机会雷达

**北邮学生大创与竞赛机会核验清单**

这是一次基于真实网页任务的校园机会信息核验实践。通过 Lexmount 云浏览器查看北京邮电大学公开通知页及赛事官网，整理参赛对象、时间、费用、材料和报名方式，并把页面冲突与访问失败保留为明确的核验状态。

## 这次完成了什么

- 查看北邮教务部、学生处 2 个公开页面和 4 个赛事官网。
- 整理 4 条候选赛事信息：3 条可继续关注，1 条因官网赛程信息关系不清而暂缓推荐。
- 保存 6 张页面证据截图；记录北邮校内信息门户在本次云端访问中连接超时。
- 信息按 2026 年 11 月 3 日的页面状态记录；报名状态可能变化，使用前应回到官网复核。

## 核验过程

1. 在 Lexmount 云浏览器打开学校公开通知页及赛事官网。
2. 按赛事对象、报名截止、费用、报名方式、提交材料记录信息。
3. 对官网不同位置的日期做交叉核对；遇到冲突时标为待确认或暂缓。
4. 保存页面截图，并将每条记录链接回其官方来源。

## 本次边界

- 本成果是 2026-11-03 的一次性网页核验快照，不是持续监控服务。
- 北邮校内信息门户在本次 Lexmount 会话中连接超时，因此未纳入校内门户检索结果。
- 以 [BUPT-NOTICE](https://github.com/yifanchen12/BUPT--NOTICE) 的校园通知整理思路作为字段设计参考；本次没有运行其本地爬虫，也没有将其代码描述为云端运行。
- 本次没有代替任何人报名、缴费或发送个人信息。
